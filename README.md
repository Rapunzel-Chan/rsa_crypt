# RSA Cryptosystem

Программная реализация асимметричной криптосистемы RSA на Python.

## Описание

Проект предназначен для учебных целей, а также может использоваться как основа для разработки прикладных средств криптографической защиты информации.

## Функциональность

- ✅ Генерация ключевой пары (размер ключа: 256, 512, 1024, 2048, 4096 бит)
- ✅ Загрузка/сохранение ключей из файлов
- ✅ Шифрование/расшифрование текста и файлов
- ✅ Преобразование текст ↔ числа (с разбиением на блоки по лекции)
- ✅ Вывод шифротекста в формате лекции (стр. 20)
- ✅ Ручной режим для проверки на маленьких ключах
- ✅ Криптоаналитические атаки (3 типа)

## 🔧 Классы и методы

### 1. `ModularArithmetic` — модульная арифметика

| Метод | Описание |
|-------|----------|
| `gcd(a, b)` | Алгоритм Евклида |
| `extended_gcd(a, b)` | Расширенный алгоритм Евклида |
| `mod_inverse(a, m)` | Обратный элемент по модулю |
| `pow_mod(base, exp, mod)` | Бинарное возведение в степень |
| `isqrt(n)` | Целочисленный квадратный корень |

### 2. `PrimeGenerator` — генерация простых чисел

| Метод | Описание |
|-------|----------|
| `miller_rabin(n, k)` | Тест Миллера-Рабина |
| `generate_prime(bits)` | Генерация простого числа |

### 3. `MessageConverter` — преобразование текст ↔ числа

| Метод | Описание |
|-------|----------|
| `text_to_blocks(text, max_value)` | Текст → блоки чисел (справа налево) |
| `blocks_to_text(blocks, block_bits, orig_len)` | Блоки → текст |
| `display_as_lecture(encrypted, n, title)` | Вывод в формате лекции |

### 4. `RSAKeyGenerator` — генерация ключей

| Метод | Описание |
|-------|----------|
| `generate()` | Генерация пары (e,n) и (d,n) |
| `save_keys_to_files()` | Сохранение ключей |
| `load_*_from_file()` | Загрузка ключей |

### 5. `RSA` — шифрование и расшифрование

| Метод | Описание |
|-------|----------|
| `encrypt_block(m, e, n)` | Шифрование блока: c = m^e mod n |
| `decrypt_block(c, d, n)` | Расшифрование блока: m = c^d mod n |
| `encrypt(text)` | Шифрование текста |
| `decrypt(encrypted, block_bits, orig_len)` | Расшифрование текста |

### 6. `Attack` — криптоаналитические атаки

| Атака | Метод | Условие |
|-------|-------|---------|
| 🔓 Факторизация перебором | `factorize_bruteforce(n)` | n < 2^50 |
| 📐 Метод Ферма | `factorize_fermat(n)` | |p-q| мало |
| 🔢 Атака Хастада | `hastad_attack(c, e=3)` | e=3, m³ < n |

### 7. `FileManager` — работа с файлами

| Метод | Описание |
|-------|----------|
| `save_encrypted_to_file()` | Сохранение шифротекста |
| `load_encrypted_from_file()` | Загрузка шифротекста |
| `save_text_to_file()` | Сохранение текста |
| `load_text_from_file()` | Загрузка текста |

## Использование
### 1. Интерактивный режим

Запустите интерактивную оболочку:

```
python main.py
```
После запуска отображается главное меню. Для выбора действия необходимо ввести соответствующую цифру и нажать Enter.
📋 Главное меню
### 📋 Главное меню
| Клавиша | Действие | Описание |
| :---: | :--- | :--- |
| **1** | 🔑 Сгенерировать ключевую пару | Генерация открытого и закрытого ключей. Доступные размеры: 256, 512, 1024, 2048, 4096 бит. Предлагается сохранить ключи в файлы. |
| **2** | 📂 Загрузить ключи из файлов | Загрузка ранее сохранённых открытого и закрытого ключей из текстовых файлов. |
| **3** | 👁️ Показать текущие ключи | Отображение ключей: открытая экспонента `e`, модуль `n`, закрытая экспонента `d`. |
| **4** | ✏️ Зашифровать текст | Ввод текста, шифрование. Вывод: ASCII-коды, блоки, шифротекст, результат по лекции, HEX. Можно сохранить в файл. |
| **5** | 📖 Расшифровать текст | Ввод шифротекста (числа через запятую), размера блока и длины сообщения. Вывод восстановленного текста. |
| **6** | 📁 Зашифровать файл | Указание входного текстового файла и выходного файла для сохранения шифротекста. |
| **7** | 📁 Расшифровать файл | Указание входного файла с шифротекстом и выходного файла для расшифрованного текста. |
| **8** | 🪓 Демонстрация атаки | Выбор атаки: перебор, метод Ферма, атака Хастада, комбинированная. Выполняется на малом ключе. |
| **9** | 🔧 Ручной режим | Ввод своих `p`, `q`, `e`. Пошаговый вывод (блоки, двоичные строки) для проверки соответствия лекции. |
| **0** | 🚪 Выход | Завершение работы программы. |

📌 Примечания по использованию

    Перед шифрованием или расшифрованием необходимо выполнить пункт 1 или 2 для загрузки ключей.

    Поддерживаемые символы: русский и английский текст, эмодзи.

    Ручной режим (пункт 9) рекомендуется использовать с небольшими простыми числами для наглядного сравнения с лекционным примером.

    Атаки (пункт 8) работают только с ключами малого размера (до 50 бит), так как это демонстрационные примеры.

    При работе с файлами входной файл должен существовать, выходной файл будет создан автоматически.

💾 Форматы файлов
Ключи (.txt)
text

# RSA PUBLIC KEY
# Created: 2026-04-30 ...
# Key size: 2048 bits
# Format: e|n
65537
123456789...

Шифротекст (.txt)
text

14
48
2148,12068,5288,12649

Где:

    строка 1 — размер блока в битах

    строка 2 — исходная длина двоичной строки

    строка 3 — блоки шифротекста через запятую
